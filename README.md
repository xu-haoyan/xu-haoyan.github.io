## 自行填写学校

1. 打开 [编辑主页](https://github.com/xu-haoyan/xu-haoyan.github.io/edit/main/index.html)。
2. 找到 `<p id="affiliation"></p>`，在标签中间填写学校或单位名称，例如：`<p id="affiliation">学校英文名称</p>`。
3. 点击 **Commit changes** 保存。GitHub Pages 会自动更新。

注册 OpenReview 前，请填写真实学校或单位，并确保主页邮箱与注册邮箱一致。

网站为纯静态 HTML，可直接编辑 `index.html`，无需安装依赖。发布来源为 `main` 分支的根目录。
